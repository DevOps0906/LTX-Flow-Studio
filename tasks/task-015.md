# task-015 LTX image-to-video 스파이크 (방식 B 가능성)

| 항목 | 내용 |
|---|---|
| 웨이브 | W5 · 선행 task-004 · 위험도 높음 · 보안 영향 의존성(I2V 파이프라인·가중치) |
| 담당 | builder(가중치 다운로드는 사용자 승인 후) → 팀장 보고 |
| 근거 | `docs/adr/ADR-004-make-mode-a-b.md`, `docs/05_STAGES.md#5` |
| 쓰기 허용 | `apps/api/spikes/**`(임시) |

## 할 것
- diffusers의 LTX I2V 파이프라인 존재·distilled/dev 호환·필요 버전 확인(문서 근거 링크)
- 조건 이미지 해상도·강도 등 파라미터 목록 확인, 720p 9:16·16:9 ~5초 세그먼트 1개 실측(VRAM·시간)
- 장면 이미지 → 720p 비율 맞춤(자르기/여백) 방법 제안

## 하지 않을 것
- 스테이지 1 본 코드 변경, 파라미터 추측 기본값 확정, 가중치 커밋
