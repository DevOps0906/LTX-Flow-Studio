# ADR-001 RTX 3060 12GB 전제 — ~5초 세그먼트 생성 후 이어붙이기

- 상태: 채택
- 날짜: 2026-11-01 (갱신: 연결 방식 확정, Dev 엔진 위험 추가)

| 항목 | 내용 |
|---|---|
| 맥락 | 원본 기획은 RTX 4090을 가정하고 15~30초·1080p를 "수십 초 내" 생성한다고 적었다. 실제 GPU는 RTX 3060 12GB라 한 번에 15~30초를 생성하는 것은 불가로 판단(팀장 결정). |
| 선택 | 스테이지 1은 720p로 ~5초 세그먼트를 순차 독립 생성하고 ffmpeg concat으로 단순 이어붙인다(15초=3, 20초=4, 30초=6). 1080p는 스테이지 2 업스케일로만. FP8·CPU offload, 동시 실행 1잡. "수십 초 내"는 distilled 기준 목표치로 재정의하고 실측(task-004)으로 확정. |
| 대안 | (1) 한 번에 전체 길이 생성 — 12GB VRAM 부족으로 버림. (2) 1080p 직접 생성 — 같은 이유로 버림. (3) 클라우드 GPU — "로컬·비용 0"과 충돌. (4) 끝프레임 조건 이어생성 — 연속성은 좋으나 복잡도 증가, 후속 후보로 보류. |
| 결과 | 얻음: 12GB에서 30초까지 가능, 세그먼트별 진행률. 잃음: 세그먼트 경계가 끊겨 보일 위험, 총 시간 증가. 세그먼트 길이·fps 확인 필요. 되돌리는 비용: 낮음(세그먼트 수=1 설정, 연결 방식은 스테이지 1 내부 교체). |
