# ADR-004 제작 방식 — A 텍스트→영상 / B 장면 이미지→영상, 사용자 선택형

- 상태: 채택(선택형 구조). 방식 B 실현 가능성은 task-015 결과에 따름
- 날짜: 2026-11-01

| 항목 | 내용 |
|---|---|
| 맥락 | 분석 결과(`05_STAGES.md#4`)로 새 영상을 만드는 길이 둘이다. 텍스트 초안만 쓰면 기존 스테이지 1을 그대로 재사용하지만 원본 구도와 멀어질 수 있다. 원본 장면 이미지를 시작 프레임으로 쓰면 구도는 가깝지만 LTX image-to-video 지원·파라미터·VRAM이 미확인이고 저작권 위험이 커진다(`01_PRD.md#6`). |
| 선택 | JobCreate `make_mode`: `t2v`(방식 A, 기본) \| `i2v`(방식 B, `analysis_id`·`keyframe_ids` 필요). 둘 다 스테이지 1 안의 입력 차이이며 세그먼트·ffmpeg concat·스테이지 2 규칙은 같다(ADR-001·ADR-002, `05_STAGES.md#5`). I2V 미지원으로 확인되면 `i2v_unavailable`로 B를 비활성하고 A만 남긴다. |
| 대안 | (1) A만 — 단순하나 확정 요구 R-B4 불충족. (2) B만 — 미확인 의존이 커서 기능 전체가 막힐 수 있음. (3) 원본 클립을 영상 조건(video-to-video)으로 — 요구에 없고 원본 재사용 위험이 더 큼, 검토 안 함. |
| 결과 | 얻음: B가 막혀도 A로 완결. 잃음: 스테이지 1 파이프라인 2종(t2v·i2v) 적재·해제 관리. **확인 필요**: diffusers LTX I2V 파이프라인·distilled/dev 호환·조건 이미지 해상도·강도 파라미터·VRAM(task-015). 확정(2026-11-01): 세그먼트마다 선택 장면 1장(Q18), 방식 B는 릴리스 2-2에서 허용·플래그 기본 꺼짐(Q12). 되돌리는 비용: 낮음(`make_mode=i2v` 제거). |
