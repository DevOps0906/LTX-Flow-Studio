# ADR-003 분석 방식 — 로컬 vs Claude API, 사용자 선택형

- 상태: 채택(선택형 구조). 키 저장 위치 = Windows 자격 증명 관리자(Q14 확정 2026-11-01). 로컬 = 릴리스 2-1, Claude = 2-2(Q10). 기본값은 미결
- 날짜: 2026-11-01

| 항목 | 내용 |
|---|---|
| 맥락 | 새로운 영상생성(`01_PRD.md#3` R-B1·R-B5)은 원본에서 장면·자막·프롬프트 초안을 뽑아야 한다. 로컬만 쓰면 비용 0이지만 RTX 3060 12GB를 LTX와 나눠 써야 하고 소형 비전모델 품질이 미확인이다. Claude만 쓰면 품질 기대는 높지만 외부 비용·키 관리·원본 외부 전송이 생긴다. |
| 선택 | 둘 다 제공, 잡마다 `analysis_mode`(`local`\|`claude`)로 선택, 기본값은 설정(S-07). `download`·`scenes`·`transcript`는 공통(로컬), `describe`·`draft`만 `Analyzer` 인터페이스 뒤에서 교체(`05_STAGES.md#4`). 기본값 제안 `local`(핵심 가치 "로컬·비용 0", `01_PRD.md#1`). |
| 대안 | (1) 로컬 단일 — 키 관리 불필요하나 품질·VRAM 위험을 피할 길이 없음. (2) Claude 단일 — 키 없으면 기능 전체 불가, 로컬 원칙과 충돌. (3) 다른 외부 비전 API — 요구에 없음, 검토 안 함. |
| 결과 | 얻음: 키 없는 사용자도 사용, 품질이 필요하면 Claude. 잃음: 분석 경로 2개 유지·테스트 2배, 키 저장(`04_API.md#6`). **확인 필요**: 로컬 비전모델·Whisper 구현체 후보와 3060 VRAM·시간(task-014), Claude 모델명·이미지 수·크기 상한·비용(task-020), Claude 오디오 입력 미확인 → 자막은 로컬 공통. 미결: 전송 프레임 수 상한(Q16). 되돌리는 비용: 낮음(Analyzer 하나 제거). |
